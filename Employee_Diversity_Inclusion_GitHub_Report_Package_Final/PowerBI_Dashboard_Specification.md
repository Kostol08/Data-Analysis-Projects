# Power BI Dashboard Specification

## Page 1 — Executive Overview
KPI cards:
- Respondents
- Avg Inclusion Score
- Avg Performance Score
- Avg Relationship Score
- Strong Performance %

Visuals:
1. Clustered column: Average score by analytical section
2. Bar chart: Lowest 5 questionnaire items
3. Bar chart: Highest 5 questionnaire items
4. Scatter: Inclusion Score vs Performance Score
5. Slicers: Gender, Age, Department, Job Level, Employment Type

## Page 2 — Workforce Profile
- Gender distribution
- Age distribution
- Department distribution
- Job level distribution
- Employment type
- Years of experience

## Page 3 — Diversity & Inclusion
- Average Diversity Score
- Average Inclusion Score
- Item-level mean scores
- Agreement percentages
- Lowest-performing D&I items

## Page 4 — Organizational Performance
- Average Performance Score
- Performance Band distribution
- Performance item scores
- Inclusion vs Performance scatter
- Relationship vs Performance scatter

## Page 5 — Employee Voice / Qualitative Themes
Use aggregated theme counts only.
Do not publish verbatim comments from the employee survey.

## Recommended dashboard title
Employee Diversity, Inclusion & Organizational Performance
